# 기사용 배차 안내 페이지 (별도 주소용)

`index.html` 하나만 회사명이 드러나지 않는 GitHub 조직의 `조직이름.github.io` 저장소에 올리면 됩니다.
내용은 사이트의 `drv.html`과 같고, 서버(Apps Script) 주소만 안에 들어 있습니다.
`drv.html`을 고치면 이 파일도 같이 바꿔 올려야 합니다.

`go.html`(출발·도착 버튼 · 애플 배차 문자 링크 `주소/go.html#링크코드`)도 같은 저장소 맨 위에 같이 올려요. 사이트의 `go.html`과 같은 내용이고 서버 주소만 들어 있어요.
