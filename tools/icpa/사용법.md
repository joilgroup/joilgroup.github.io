# 인천항 임시출입 신청 프로그램 (1차)

## 처음 한 번
1. https://nodejs.org 에서 **LTS** 버전을 설치해요 (다음 → 다음).
2. 이 폴더(`icpa`)를 원하는 곳(예: `C:\JOIL\icpa`)에 풀어 두고, `인천항출입등록.bat`을 오른쪽 클릭 → 보내기 → **바탕 화면에 바로 가기 만들기**.
3. 처음 실행하면 `설정.json`이 생겨요. 메모장으로 열어 **방문업체 사업자등록번호**(000-00-00000 형식)를 넣고 저장해요.
   - 크롬이 없으면 `"브라우저": "edge"`로 바꿔요.

## 매번
1. JOIL 배차시트 → 삼다수 → **삼다수-인천항** 탭 → 배차 표 위 **🛂 출입등록 복사**
   (운전원·생년월일·연락처가 빈 기사는 빠지고 알림에 이름이 나와요)
2. 바탕 화면 **인천항출입등록** 더블클릭 → 처음 한 번은 준비(1~2분)
3. 1단계(이름·생년월일·성별·휴대전화·방문업체·동의·서약)는 자동으로 넣고 **등록**까지 눌러요.

## 1차 버전에서 직접 할 일 (한 번만)
- 1단계가 끝나면 **기록 모드**가 돼요. 브라우저에서 날짜 선택부터 마지막 "완료" 팝업까지 평소처럼 직접 진행해 주세요.
- 끝나면 검은 창에서 Enter → 폴더에 `기록_날짜.json`이 생겨요. 이 파일을 Claude에게 보내 주시면 2단계부터 끝까지 자동으로 만들어요.
- 기록 파일에는 기사 이름·생년월일·전화·차량번호가 `{이름}` 같은 표시로 바뀌어 저장돼요.
- 이번엔 첫 기사만 진행해요. 나머지 기사는 직접 신청해 주세요.
