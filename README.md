# JOIL · 조일그룹 견적·실적 시스템

상단 메뉴: 홈 · 견적▾(단건·대량·견적접수·견적모음·조회기록) · 업체·자료▾(배차검색·거래처·업체단가·서류함) · 일정·정보▾(일정·물류정보) · 분석 · 관리자

상차지와 하차지를 넣으면 거리, 톤수별(1~25톤) 운임, 밀크런 유류비·통행료가 한 번에 나오는 사내 견적 도구입니다. 최대 1000건 대량 계산도 됩니다.

- **홈**: 오늘 할 일·오늘 휴가 · 오늘 경유가와 추이 · 최근 실적과 확인해 볼 매출처 · 만료 임박 서류 · 최근 내 견적·조회 · 바로 계산 (권한에 맞는 카드만)
- **일정**: 한 달 달력에 공휴일(구글 캘린더 "대한민국의 휴일")·회사 휴무일·휴가·근무·할 일·견적 회신 기한·서류 만료·일정 표시 · 업체별 반복 할 일(일회/매월 말일/매월 N일/매주/매년, 주말·공휴일이면 앞·다음 영업일로) 체크하면 사라지고 완료 기록은 남음 · 담당자별 휴가(연차·반차·병가·경조·공가·대체휴무)와 추가근무(야간근무·휴일근무·당직, 시각·시간), 연차 부여·사용·잔여 · 월별 사람별 추가근무 시간 합계와 엑셀 · 계정 없는 직원 · 엑셀 가져오기 · 당직 순번 규칙(주 단위 또는 정한 요일·공휴일마다, 한 주만 교대·취소) · 여러 날 기록은 주 단위 막대로 이어서 표시
- **배차검색**: 분석에 올린 월별 엑셀에서 업체·상차지·하차지·중량(포함/정확히)·차량번호·기사명·전화번호·비고를 칸마다 검색 · 숨긴 매출처 제외 · 차량·기사 눌러 다시 찾기 · 엑셀 (별도 '배차검색' 권한)
- **관심 종목**: 홈 카드에 내가 고른 국내·해외 종목 5개 (네이버 금융 시세, 장중 1분마다 — 미국은 한국 시간 밤, 누르면 3개월 그래프)
- **팀 공지**: 홈 맨 위 공지 (누구나 쓰기, 📌 고정은 관리자)
- **주간 업무 요약**: 이번 주 당직·휴가·할 일·견적 회신·계약/서류 만료 + 지난주 견적·추가근무를 사이트에서 보고, 매주 월요일 오전 8시 메일 발송 (금액 제외)
- **시간외근무일지**: 회사 양식 그대로 사람별·월별 엑셀 (부서·사업자 자동, 당직은 끝나는 날 기준)
- **거래처 카드**: 담당자·연락처·계약 기간·결제 조건 + 그 업체의 견적 접수·견적모음·단가표·할 일·단가 변경 기록 한 화면, 계약 만료 알림
- **직원 목록** (관리자): 이름·사업자·부서·메일·계정 연결·재직·주간 요약 받기
- 견적 접수함·서류함의 엑셀 첨부 미리보기
- **물류 정보**: 경유가 상세(주식 화면처럼 기간별 그래프·최고·최저·등락) · 물류 뉴스(구글 뉴스 키워드 수집, 관리자가 키워드·제외 단어 설정) · 도별 날씨와 운행 주의
- **도움말**: 오른쪽 위 "도움말"에서 내 권한으로 쓸 수 있는 메뉴 사용법
- **단건 계산**: 카카오 경로 거리 → 톤수별 금액(기본타리프 + 하행 % + 지역할증) · 결과 엑셀에는 계산식이 들어가서 할증을 고치면 합계가 다시 계산됨
- **밀크런**: 기준 톤수 하나로 경로별 유류비 + 통행료(편도·왕복)를 따로 계산
- **대량 계산**: 최대 1000건 (상차지 1곳 → 여러 하차지, 또는 2열 붙여넣기) · 사이트에서 바로 조회 · 엑셀(.xlsx) 다운로드 · 실패 건만 다시 계산 · 주소·경로 영구 캐시
- **조회기록**: 모든 조회를 그때 금액 그대로 자동 보관(기본 90일) · 상세보기 · 엑셀 · 현재 단가로 다시 계산 · 직원은 본인 것만
- **금액 조정**: 결과 표에서 열(톤수)·행(경로)·칸 하나를 직접 조정(할인은 -), 견적모음에 같이 저장, 변경 기록 · 엑셀 수식에도 반영
- **타리프 버전**: 계산 기준(타리프·할증·반올림)을 버전으로 보관 → 저장된 견적에 **구간 추가** 시 그 견적 당시 기준으로 계산 · 시트의 타리프 탭을 직접 고쳐도 바로 반영 · 0원·빈칸 경고
- **특수 추가운임**: 냉동·위험물·리프트 등 회사 기준표(톤수별 금액 또는 %)를 관리자가 설정 · 계산 시 골라서 적용 · 업체별로 덮어쓰기 · 엑셀 수식 포함
- **업체 단가표**: 통합 양식 다운로드 → 업로드(톤수 표기 자동 정리) → 조회 · 우리 타리프와 비교(차이 원·%) · 그 구간으로 바로 새 견적
- **견적 접수함**: 받은 견적 요청(메일 제목·본문·원본 첨부)과 제출 파일·제출 단가를 한 건으로 기록 · 상태(접수→검토중→제출→수주/미수주) · 견적모음 연결 시 상태 자동 맞춤 · 회신 기한 알림 · 팀 공유
- **견적모음**: 결과를 견적명·거래처·메모·진행 상태(작성/제출/수주/미수주)와 함께 저장 · 검색·상태별 보기 · 기간 제한 없이 보관
- **매출매입 분석**: 사업자별(조일물류·명일로지스·조일로지스) 월 엑셀 업로드(합계 줄 자동 대조, 같은 달은 덮어쓰기) · 기간·사업자·매출처·발지·착지·기사·차량·중량으로 자유롭게 걸러 보기 · 월별 추이·이익률 · 순위표 · 상세 내역 엑셀 · 매출처 표시 이름/묶기/숨기기 · 제외·분류 규칙(인건비·보관료 등)
- **견적서**: 단건·대량 결과와 견적모음에서 바로 견적서 만들기 · 사업자 3곳별 공급자 정보·직인 자동 입력 · 인쇄/PDF · 같은 양식의 엑셀(직인 포함)
- **서류함**: 사업자등록증·통장사본·허가증·견적서 양식 등을 구글 드라이브 비공개 폴더에 보관 · 미리보기(PDF·이미지) · 다운로드 · 여러 개 ZIP · 만료일 알림
- **견적 ↔ 실적 연결**: 견적모음 상세에서 매출처·경로를 연결하면 견적 단가와 실제 월별 매출·매입·이익 비교 (분석 권한)
- **주소 자동완성**: 지금까지 조회한 주소와 실적 지명을 입력칸에서 추천
- **단가 변경 기록**: 재계약·유가연동·구두 합의 등 엑셀에 없는 단가 변경을 매출처·월·경로별로 기록 → 그래프 📌 표시, 확인해 볼 곳·매출처 상세·월간 보고서에 같이 표시 · 엑셀 일괄 입력
- **분석 추가 기능**: 단가 이상치(같은 경로·중량 대비) · 매출처 상세 카드 · 월간 보고서(인쇄/PDF·엑셀)
- **유가 기록**: 오피넷 전국 평균 경유가를 매일 자동 기록(최근 7일치로 빈 날 메움) · 과거 유가 엑셀 가져오기 · 추이 그래프 · 견적 계산은 기록된 최신 값 사용
- **메뉴 권한**: 계정마다 견적 / 분석 / 배차검색 / 관리자 권한을 따로 설정
- **관리자 페이지**: 타리프(1~600km × 9톤수), 지역 할증, 하행 %, 밀크런 기준 톤수·편도/왕복, 연비, 통행료 차종, 금액 반올림, 대량 최대 건수, 조회 상세 보관 기간, 계정 발급·중지·메뉴 권한, 분석 데이터 업로드, 매출처 설정, 분석 규칙, 유가 기록, 회사 정보(견적서), 캐시 관리
- **보안**: 단가와 API 키는 비공개 구글 시트와 Apps Script에만 저장됩니다. 이 저장소에는 화면 코드만 있습니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html`, `assets/` | 화면 (GitHub Pages) |
| `config.js` | 서버(Apps Script) 주소. 비어 있으면 **데모 모드** |
| `apps-script/Code.js` | 서버 코드. Apps Script에 붙여넣기 |
| `apps-script/Calc.js` | 계산 규칙. 서버와 데모 모드가 함께 사용 |
| `SETUP.md` | **설치 안내서** |

## 데모 모드

`config.js`의 `API_URL`이 비어 있으면 임의 단가와 주요 도시 좌표로 동작합니다.
아이디 `admin`, 비밀번호 `demo1234`로 들어갈 수 있습니다.

설치 방법은 [SETUP.md](SETUP.md)를 보세요.
